AI 心理健康助手 · 后端服务

服务已启动。这是一个纯 API 服务，没有内置前端页面。

用户

POST/api/user/register 注册
POST/api/user/login 登录，返回 JWT
POST/api/user/logout 登出（token 进黑名单）

AI 对话

POST/api/psychological-chat/session/start 新建会话
GET/api/psychological-chat/sessions 会话列表
GET/api/psychological-chat/sessions/{id}/messages 会话消息
POST/api/psychological-chat/stream SSE 流式对话

情绪日记

GET/api/emotion-diary/my 我的日记
POST/api/emotion-diary 新增 / 更新当天日记
POST/api/emotion-diary/{id}/analyze AI 情绪分析
除登录、注册、登出外，其余接口都需要在请求头带上 token: <JWT>。
统一返回 { code, message, data }；code = "200" 为成功，认证类错误码以 A0 开头。
